# Новояворівськ+

Android-застосунок для перегляду графіків планових відключень електроенергії та стану послуг у населених пунктах Новояворівської територіальної громади.

## Можливості

- додавання кількох адрес і груп;
- графіки відключень для Нафтогаз Тепло та Львівобленерго;
- окремі сторінки адрес із навігацією назад;
- кешування даних і автоматичне оновлення кожні 10 хвилин;
- оновлення даних для всіх збережених груп;
- локальні сповіщення за 30, 20 і 10 хвилин до відключення;
- темна та світла тема;
- пошук населених пунктів, вулиць і будинків Львівобленерго.

## Вимоги

- Android Studio;
- JDK 17;
- Android SDK;
- доступ до API сервера.

## Запуск

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/Iway1231/NovoyavorivskPlus.git
   ```

2. Відкрийте папку проєкту в Android Studio.
3. Дочекайтеся синхронізації Gradle.
4. Запустіть застосунок на емуляторі або Android-пристрої.

Для збірки debug APK:

```bash
./gradlew assembleDebug
```

APK буде створено у `app/build/outputs/apk/debug/app-debug.apk`.

## API

Адреси API налаштовані у `app/src/main/java/com/iway1231/novoyavorivskplus/api/ApiClient.kt`. Перед запуском змініть локальну та резервну адресу на власні сервери.

Застосунок підтримує автоматичне перемикання на резервний сервер, якщо локальний сервер недоступний.

## Кеш

Дані графіків і статусів зберігаються локально. Кеш оновлюється не частіше одного разу на 10 хвилин, а під час ручного оновлення актуальні дані завантажуються для всіх збережених груп.
