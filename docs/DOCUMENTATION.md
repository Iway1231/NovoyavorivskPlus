# Новояворівськ+

Повна документація Android-застосунку для перегляду графіків відключень та стану міських сервісів у населених пунктах Новояворівської територіальної громади.

## 1. Призначення

Застосунок отримує дані з `power-backend` і показує їх у єдиному інтерфейсі. Підтримуються два оператори:

- **Нафтогаз Тепло** — групи графіків, адреси або населені пункти без адрес;
- **Львівобленерго** — населений пункт, вулиця та будинок через окремі адресні API.

Застосунок не є постачальником електроенергії та не гарантує, що опублікований графік збігатиметься з фактичними відключеннями.

## 2. Основні можливості

- кілька збережених адрес і груп;
- окремий перегляд графіка для кожної збереженої позиції;
- вибір населеного пункту, вулиці та будинку Львівобленерго;
- вибір лише населеного пункту для груп Нафтогаз Тепло, де адреси не надані API;
- кеш графіків і статусів на пристрої;
- оновлення кешу кожні 10 хвилин;
- фонове оновлення після закриття інтерфейсу;
- повторні спроби після тимчасової недоступності API;
- сповіщення за 30, 20 і 10 хвилин до запланованого відключення;
- окремі сповіщення про появу нового графіка для кожного оператора;
- попередження, якщо вже опублікований графік змінився;
- відображення часу останнього оновлення;
- темна та світла тема;
- меню з підтримкою проєкту, контактами та інформацією про застосунок.

Сповіщення про відключення води не створюються. Водний сервіс може відображатися на екрані як інформаційна секція без окремих push/local-повідомлень.

## 3. Структура проєкту

```text
app/src/main/java/com/iway1231/novoyavorivskplus/
├── MainActivity.kt             # UI, навігація, вибір адрес і відображення даних
├── BackgroundRefresh.kt        # фонове оновлення кешу через AlarmManager
├── OutageNotifications.kt      # локальні сповіщення перед відключенням
├── api/
│   ├── ApiClient.kt             # Retrofit, локальний сервер і резервний Tailscale URL
│   └── PowerApi.kt              # оголошення API-методів
└── ui/theme/                   # кольори, типографіка і тема Compose
```

Інтерфейс написаний на Jetpack Compose. Мережеві запити виконуються Retrofit/OkHttp, дані представлені `JsonObject` без окремого шару бази даних.

## 4. Сервер і API

Адреси налаштовані у `app/src/main/java/com/iway1231/novoyavorivskplus/api/ApiClient.kt`:

```text
Локальна адреса:  http://192.168.0.112:8000/
Резервна адреса: https://iway1231-server1.tail04685e.ts.net/
```

Застосунок спочатку використовує локальний сервер. Якщо локальне з'єднання завершується мережевою помилкою, `AutoFallbackInterceptor` повторює запит через Tailscale адресу.

Використовувані endpoint-и:

| Метод | Endpoint | Призначення |
|---|---|---|
| GET | `/api/v1/health` | перевірка доступності API |
| GET | `/api/v1/status` | загальний статус електромережі |
| GET | `/api/v1/app/bootstrap` | початкові дані застосунку |
| GET | `/api/v1/naftogaz/groups` | групи Нафтогаз Тепло та їх адресні дані |
| GET | `/api/v1/mobile/home?operator=...&group=...` | секції сервісів і графік групи |
| GET | `/api/v1/loe/cities` | населені пункти Львівобленерго |
| GET | `/api/v1/loe/streets?city=...` | вулиці населеного пункту |
| GET | `/api/v1/loe/buildings?city=...&street=...` | будинки вулиці |
| GET | `/api/v1/loe/lookup?...` | визначення групи будинку |

Після зміни сервера потрібно змінити `LOCAL_URL` і резервний host у `ApiClient.kt`, зібрати APK та встановити його на пристрій.

## 5. Кеш

Кеш зберігається у `SharedPreferences` з назвою `settings`.

Основні ключі:

- `cache_home_naftogaz_<group>` — графік групи Нафтогаз Тепло;
- `cache_home_loe_<group>` — графік групи Львівобленерго;
- `cache_home_time_<id>` — час отримання конкретного графіка;
- `cache_power` і `cache_power_time` — загальний статус мережі;
- `cache_groups` і `cache_groups_time` — список груп Нафтогаз Тепло;
- `saved_locations` — збережені групи та адреси.

Алгоритм роботи:

1. Екран спочатку показує останній кеш, щоб не чекати мережу.
2. Якщо кеш молодший за 10 хвилин, мережевий запит не виконується.
3. Після завершення 10 хвилин виконується запит до API.
4. Нові дані повністю замінюють старий запис кешу.
5. Якщо API недоступне, старий кеш залишається доступним, а наступна спроба виконується автоматично.

Перехід на сторінку адреси не повинен самостійно створювати новий запит, якщо кеш ще актуальний.

## 6. Фонове оновлення

`BackgroundRefreshReceiver` реєструє повторюваний `AlarmManager` з інтервалом 10 хвилин. Він працює:

- коли екран застосунку закритий;
- після виходу із застосунку;
- після перезавантаження телефона, якщо застосунок уже запускався;
- для всіх збережених груп, а не лише для відкритої на екрані.

Після першого запуску застосунок просить виключити себе з оптимізації батареї. Це підвищує надійність фонових запитів.

### Обмеження Android

Кнопка **«Примусово зупинити»** повністю блокує фонові задачі до наступного запуску застосунку. Обійти це системне обмеження неможливо. На деяких виробниках також потрібно вручну дозволити автозапуск:

- Xiaomi/MIUI: **Налаштування → Програми → Дозволи → Автозапуск**;
- Samsung: **Налаштування → Обслуговування пристрою → Батарея → Фонове використання**;
- Huawei: **Налаштування → Батарея → Запуск програм**.

## 7. Сповіщення

### Перед відключенням

Для опублікованих інтервалів створюються локальні сповіщення за:

- 30 хвилин;
- 20 хвилин;
- 10 хвилин.

Сповіщення плануються через `AlarmManager` і містять адресу, час початку та кількість хвилин до відключення.

### Новий або змінений графік

Фоновий обробник порівнює секцію електроенергії з попередньою версією:

- якщо API вперше повернуло дату та інтервали — **«З’явився новий графік»**;
- якщо опублікований графік змінився — **«Увага: графік змінився»**;
- якщо дата або інтервали відсутні — сповіщення не надсилається.

Для Львівобленерго і Нафтогаз Тепло використовуються окремі канали повідомлень Android.

На Android 13 і новіших версіях потрібно дозволити `POST_NOTIFICATIONS`.

## 8. Додавання адреси

### Нафтогаз Тепло

1. Натисніть `+` або **Додати адресу**.
2. Оберіть населений пункт.
3. Якщо група має адреси — оберіть вулицю та будинок.
4. Якщо група не має адрес — оберіть населений пункт без вулиці та будинку.
5. Застосунок збереже групу і показуватиме її графік.

### Львівобленерго

1. Натисніть **Додати адресу Львівобленерго**.
2. Оберіть населений пункт Новояворівської ОТГ.
3. Знайдіть вулицю та будинок.
4. Застосунок виконає lookup і збереже визначену групу.

До списку Львівобленерго входять лише населені пункти Новояворівської ОТГ.

## 9. Збірка та встановлення

### Вимоги

- Android Studio;
- Android SDK з compileSdk 36;
- JDK 17 або сумісна версія, налаштована в Android Studio;
- доступ до Gradle dependencies під час першої збірки.

### Debug APK

У PowerShell:

```powershell
cd C:\Users\Admin\AndroidStudioProjects\NovoyavorivskPlus
.\gradlew.bat --no-daemon assembleDebug
```

APK буде у:

```text
app\build\outputs\apk\debug\app-debug.apk
```

В Android Studio можна натиснути **Run** для встановлення на підключений телефон. На телефоні потрібно дозволити встановлення через USB та налагодження USB.

## 10. Тестування

### Перевірка API

```powershell
Invoke-WebRequest http://192.168.0.112:8000/health
```

Очікується HTTP 200 і JSON зі статусом `ok`.

### Перевірка кешу

1. Відкрити застосунок і дочекатися графіка.
2. Вимкнути сервер.
3. Перейти між адресами — останні дані мають залишатися на екрані.
4. Увімкнути сервер.
5. Дочекатися наступного 10-хвилинного циклу або натиснути ручне оновлення.

### Перевірка сповіщень

У меню є тестове сповіщення. Для реальних сповіщень потрібні дата й інтервали у відповіді API, а також дозвіл Android на повідомлення.

## 11. Типові проблеми

### Немає з'єднання з сервером

- перевірте, що сервер слухає `0.0.0.0:8000`, а не лише `127.0.0.1`;
- перевірте доступність `192.168.0.112` у тій самій Wi-Fi мережі;
- перевірте Tailscale на сервері та телефоні;
- перевірте Windows Firewall для TCP-порту 8000.

### Не приходять фонові повідомлення

- дозвольте повідомлення;
- вимкніть оптимізацію батареї;
- дозвольте автозапуск;
- не використовуйте «Примусово зупинити»;
- переконайтеся, що в застосунку є збережена група.

### Графік не показується

API може повернути секцію електроенергії без дати або інтервалів. У такому випадку графік вважається ще не опублікованим і сповіщення не створюється.

## 12. Безпека та приватність

Застосунок не має власного облікового запису. Збережені адреси та налаштування зберігаються локально у пам'яті Android-застосунку. Мережеві запити містять лише параметри, потрібні для отримання групи або графіка.
